# 이전 시스템 문서

이 폴더는 이전 아키텍처·설치·마이그레이션·디자인 문서를 보관합니다. 본문은 당시 상태를 설명하며 현재 설정·작업 지침으로 사용하지 않습니다.

현재 문서 선택은 [docs/README.md](../README.md), 설치는 [setup](../setup.md), 배포는 [release](../release.md)를 사용합니다.

## 보관 범위

- Google/Naver 로그인과 JWT 전환 자료.
- 이전 Cloud Run 관리자 API·WebSocket 릴레이 구조.
- 이전 GitHub Actions/태그 릴리스·Docker·Electron 이식 절차.
- 당시 CSS·플로팅 알림·Zoho 설정과 검토 자료.
- 과거 프로젝트 소개·계정 추가·빠른 시작·임시 진행도.

`계정추가법.md`와 `ADMIN_ACCOUNT_GUIDE.md` 등은 같은 과거 흐름을 다른 시점에 설명합니다. 현재 계정 생성 절차는 setup에 통합했으며 이 문서들은 기록으로 유지합니다. `임시-진행도.md`와 `ZOHO_IMPLEMENTATION_REVIEW.md`도 당시 계획·리뷰 기록입니다. 원문 속 완료·pending은 최신 상태로 해석하지 않습니다.

내부 링크·파일 경로·버전은 과거 배치 기준일 수 있습니다. 과거 문서 전체를 현재 구조에 맞춰 고쳐 원래 기록을 바꾸지 않습니다. `../../legacy/`는 별도의 이전 소스 트리입니다.
